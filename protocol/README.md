# Ant protocol client

The codecs mirror the native program's fixed account layouts and little-endian instruction format. Amounts are integer lamports or ANT base units. A client must derive PDAs with `solana.mjs`, use the legacy SPL Token program, and obtain the configured mint and network identity from the on-chain config.

The current fixed account sizes are 272 bytes for config, 374 bytes for a round, and 642 bytes for a capsule. The browser entry point exports these sizes for exact preflight checks. No production program ID or mint is embedded in this package.

`settleLocalFixture` exists only for disposable Surfpool rounds whose config explicitly records `local-fixture` and whose executable is owned by the legacy loader used for local artifact injection. It accepts authority-signed test buckets and cannot run in other modes. Disabled and Pyth initialization require the authenticated Upgradeable Loader ProgramData authority.

Pyth settlement uses instruction `10` with no data after the tag. Its ordered accounts are config, writable round, SOL entry-boundary `PriceUpdateV2`, SOL observation-boundary `PriceUpdateV2`, BTC entry-boundary `PriceUpdateV2`, and BTC observation-boundary `PriceUpdateV2`. The account decoder follows the official `pyth-solana-receiver-sdk` `2.0.0` `PriceUpdateV2` layout. The program accepts only the configured account owner and feed IDs, `VerificationLevel::Full`, a signed update whose `(prev_publish_time, publish_time]` interval contains the exact boundary, the configured maximum interval gap and confidence ratio, and matching exponents within each pair. Each valid question settles independently and stores its two accepted price records in an evidence-hash chain. An unavailable question remains pending until another permissionless attempt or deterministic timeout cancellation; an accepted question cannot be replaced. Production activation requires an authenticated historical-update retrieval and receiver-posting proof. HTTP price numbers are never settlement evidence. Local fixture values are never Pyth evidence.

The commitment is SHA-256 over the byte concatenation `ant-capsule-v1 || program_id || network_identity || mint || round_id_le_u64 || wallet || schema_le_u16 || answers[2] || salt[32]`. The encrypted capsule bytes are bounded to 512 bytes and stored on-chain; plaintext answers and salt stay in the user's recovery file.
